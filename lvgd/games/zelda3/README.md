# Zelda 3 486

A reimplementation of Zelda 3 for the PC 486

Based on https://github.com/snesrev/zelda3/tree/master

# Building

1. Open a terminal
2. Run get_python_libs.bat
3. Place your US ROM file named `zelda3.sfc` in the root of the project (alongside the Makefile)
4. Run extract_assets.bat
5. Delete the ROM file (it's no longer needed).
6. Run make to compile.

The binary is in the folder linux, move it to the root of the project and run it.
